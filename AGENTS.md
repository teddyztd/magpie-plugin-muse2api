# magpie-plugin-muse2api

Magpie (OpenCode v1) provider plugin that bridges [muse2api](https://github.com/czg86389-hub/muse2api) — an OpenAI-compatible gateway in front of muse.ai — into Magpie's provider registry.

## Agent skills

### Issue tracker

Issues and specs for this repo live as GitHub issues in `teddyztd/magpie-plugin-muse2api`. Use the `gh` CLI for all operations; the full conventions (native blocked-by dependencies, sub-issues, labels) are in `docs/agents/issue-tracker.md`.

### Domain docs

This repo uses a single-context domain-doc layout: `GLOSSARY.md` at the root and decisions recorded in `docs/adr/`. How to consume them is in `docs/agents/domain.md`.
